# TTMB Filters and Blacklist/Whitelists

## Manually Curated Filters and Categories

This is where mods are categorized (based on what they add or change) and also placed into specific filters (such as AI-Generated, not very high quality, etc).

## Blacklists/Whitelists
### for automatic detection filters

Turtle's TABS Mod Browser has various filters to improve the experience and hide mods you may not want to see, but sometimes mods get detected when they should not be, or should be hidden but are not detected. So, this GitHub provides explicit whitelists and blacklists for TTMB, so even when the filter is wrong, corrections can still be made.
